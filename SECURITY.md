# Sicurezza / Security

## 🇮🇹 Italiano

PoliOS Welcome installa software con privilegi di root a partire da un elenco di corsi scaricato da questo repository. Se trovi un problema di sicurezza (per esempio un modo per far installare pacchetti non previsti, o per leggere la password del Wi-Fi), **non aprire una segnalazione pubblica**: usa [Segnala una vulnerabilità](../../security/advisories/new) (scheda *Security* del repository). Risponderemo appena possibile.

Come è protetto l'elenco dei corsi: solo URL `https://raw.githubusercontent.com/`, dimensione massima, solo pacchetti apt/Flathub o ricette integrate (mai URL o comandi nell'elenco), e `main` richiede revisione.

## 🇬🇧 English

PoliOS Welcome installs software as root from a course list downloaded from this repository. If you find a security problem (for example a way to make it install unintended packages, or to read the Wi-Fi password), **do not open a public issue**: use [Report a vulnerability](../../security/advisories/new) (the repository's *Security* tab). We will reply as soon as we can.

How the course list is protected: `https://raw.githubusercontent.com/` URLs only, size cap, only apt/Flathub packages or built-in recipes (never URLs or commands in the list), and `main` requires review.
